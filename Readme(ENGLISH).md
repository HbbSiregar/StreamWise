# StreamWise

**StreamWise** is a data analysis project aiming to explore and process movie and genre data from various sources, particularly Rotten Tomatoes. This project uses data cleaning, exploration, and visualization techniques to gain insights into movie trends, genre popularity, and correlations useful for understanding viewing patterns.

## Folder and File Structure

- `StreamWise(Bahasa).ipynb`: Primary Jupyter notebook in Indonesian containing the complete analysis.
- `StreamWise(English).ipynb`: Primary Jupyter notebook in English for analysis.
- `Genre_Table.xlsx`: Movie genre reference data table.
- `Rotten Tomatoes Movies.csv`: Movie dataset in CSV format.
- `Rotten Tomatoes Movies Clean.xlsx`: Cleaned movie dataset.
- `StreamWise_Presentation(Bahasa).pptx`: Presentation of the analysis results in Indonesian.
- `StreamWise.twbx`: Tableau workbook for interactive data visualization.
- `Readme.md`: Project documentation.

## Project Description

This project focuses on:

- Cleaning and preparing movie data from Rotten Tomatoes
- Categorizing movies by genre
- Exploring trends and patterns in movie and genre data
- Creating data visualizations to assist understanding of the analysis results

All processes and analytical steps can be followed in the Jupyter notebook files.

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/HbbSiregar/StreamWise.git
2. Set up the Python environment with libraries such as pandas, matplotlib, seaborn, and others (check requirements if available).
3. Run `StreamWise.ipynb` to follow the data analysis step-by-step.
4. Use the Tableau files (.twbx and .twbr) for more interactive visual exploration.
5. The presentation is located in `StreamWise.pptx` summarizing the key insights.

## Results and Visualization

The detailed analysis results can be viewed inside the Jupyter notebooks and the PowerPoint presentation. For interactive visualization, use the Tableau workbook.
